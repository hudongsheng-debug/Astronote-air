## 快速开始
- 从书架打开笔记本，查看初始示例页；也可新建笔记本。
- 添加图像页，或导入已有 .astronote 标注包。
- 选择“编辑此页”，添加标注并填写观察笔记。
- 返回书页浏览或添加书签；笔记在本机自动保存。
- 从编辑页导出标注包、PNG 或文字笔记。

## 数据和使用边界
标注工具为点位、文字与矩形区域，不是自由手写画布。FITS 支持首个可读的未压缩二维图像，不支持压缩 FITS、立方体或 WCS 天球坐标标注。记录保留参考预览，预览/PNG 最长边 1024 像素，不是完整 FITS 备份；原始像素不被修改。

## 保存与备份
笔记本、页面、创建时间、参考预览、观察笔记、标注、书签和书架顺序保存在本机应用空间。为识别源图，标注包可包含文件名、尺寸、HDU 编号和内容指纹；不包含完整原始 FITS。
卸载或删除应用前，请先导出重要资料并保留原始文件。仅卸载应用与删除应用的系统行为可能不同；请按 iPad 的实际选项确认。

## 常见问题

### 可以像绘画应用一样自由手写吗？
本版是点位、文字与矩形标注工具，不提供自由笔迹画布。

### 笔记包是否包含原始 FITS？
不包含完整原始 FITS，主要保存参考预览、标注、笔记与识别信息。请保留源文件。

### 文件选择器里找不到文件，或云文件无法读取？
先在系统“文件”中确认文件已完整下载、你有访问权限，且格式受本应用支持。重试时优先使用“我的 iPad”中的本地副本。扩展名相同不保证内部数据结构一致。

### 怎样报告问题？
说明你执行的操作、预期结果与实际结果，并提供不含敏感信息的截图。若需要样例，优先构造小型合成文件。没有源文件也可以先报告，我们会根据描述继续沟通。

## Quick start
- Open a notebook on the shelf to view the initial example, or create a notebook.
- Add an image page or import an existing .astronote package.
- Choose Edit Page, add annotations, and write observation notes.
- Return to reading or bookmark a page; notes save locally automatically.
- Export a package, PNG, or text notes from the editor.

## Data and scope
Annotation tools are point, text, and rectangle tools, not a freehand drawing canvas. FITS support reads the first supported uncompressed 2D image, not compressed FITS, cubes, or celestial/WCS annotations. Journals keep reference previews; preview/PNG long edges are limited to 1024 pixels and are not complete FITS backups. Original pixels are unchanged.

## Saving and backups
Notebooks, pages, creation dates, reference previews, observations, annotations, bookmarks, and shelf order are stored locally in the app. Annotation packages can include filenames, dimensions, HDU identifiers, and content fingerprints to identify source images, but not complete original FITS files.
Export important work and retain source files before offloading or deleting the app. Offload App and Delete App can have different effects; check the actual system option on your iPad.

## Frequently asked questions

### Can I draw freehand as in a painting app?
This version provides point, text, and rectangle annotations, not a freehand ink canvas.

### Does a package contain the original FITS file?
It does not contain the complete source FITS. It primarily stores a reference preview, annotations, notes, and source identity information. Keep the source file separately.

### A file is missing from the picker, or a cloud file will not open
In Files, confirm the file is fully downloaded, accessible, and in a supported format. Try a local copy under On My iPad. A matching filename extension does not guarantee a supported internal structure.

### How should I report a problem?
Describe the action, expected result, and actual result, with screenshots free of sensitive information. If an example is needed, prefer a small synthetic file. You may report the problem without a source file first; we can follow up from your description.

## Privacy
No account is required and core processing takes place on your device. Read the privacy policy in this folder for local storage, file services, and voluntary support communications.
